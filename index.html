01 / GETTING STARTED

처음 시작하기

전용 접속기로 서버에 입장한 뒤 기본 메뉴와 스폰 지역부터 확인하세요. 스폰에서 상점과 주요 NPC·콘텐츠를 둘러볼 수 있습니다.

  1. 버전과 필요한 파일을 확인하고 서버에 접속합니다.
  2. 스폰 지역을 둘러보고 안내 NPC와 메뉴를 확인합니다.
  3. 원하는 생활 콘텐츠 또는 탐험 콘텐츠를 선택합니다.
  4. 명령어 목록에서 이동·상점 관련 기능을 확인합니다.
TIP · 명령어는 플러그인 설정에 따라 달라질 수 있습니다.

07 / SPECIAL ENCHANTS

특수 마법부여 도감

하소리촌은 바닐라의 보호·효율·날카로움 외에도 별도의 특수 마법부여 도감을 제공합니다. 실제 인게임 화면에는 방어구, 도구, 엔더의 눈 아이콘, 활, 검으로 구분된 탭이 표시됩니다.

실제 화면 확인

🛡️ 얼음 방패

  • 효과: 공격자를 얼리고 공격자에게 적용
  • 레벨: 1~3
  • 적용 대상: 방어구 (갑옷 아이콘)
  • 표시 가격: 3,500 영혼

공격을 받았을 때 상대에게 상태 이상을 부여하는 방어형 마법부여입니다. 화면에 표시된 설명 기준으로 작성했으며, 발동 확률과 지속 시간은 확인되지 않았습니다.

📚 마법부여 카테고리

  • 🛡️ 방어구 탭 — 방어구에 사용하는 효과
  • ⛏️ 도구 탭 — 채굴 및 도구 관련 효과 분류
  • 🟢 특수 탭 — 엔더의 눈 아이콘으로 표시
  • 🏹 활 탭 — 원거리 무기 관련 분류
  • ⚔️ 검 탭 — 근접 무기 관련 분류

탭 이름은 화면 아이콘에 따른 구분이며, 다른 마법부여의 구체적인 명칭·성능은 확인되지 않았습니다.

실제 게임 화면: 방어구 탭에 표시된 ‘얼음 방패’의 설명·레벨·가격.

이용 팁　특수 마법부여를 고를 때는 ①장비 대상 → ②레벨 범위 → ③발동 방식 → ④영혼 비용 순서로 비교하세요. 효과 목록을 정확하게 확장하려면 나머지 책의 툴팁 또는 플러그인 설정이 필요합니다.
08 / ADVANCED FISHING

확장 낚시 · 직업 능력

바닐라 낚시와 달리, 하소리촌은 낚시 관련 스킬과 별도의 교환·상점 메뉴를 운영합니다. 단순히 낚싯대를 던지는 것에서 끝나지 않고 낚시 경험치와 관련 능력을 성장시킬 수 있습니다.

실제 화면 확인

🎣 낚시꾼 II

스킬 메뉴에서 확인되는 능력입니다.

  • 효과: 낚시 경험치 20% 증가
  • 표시 상태: 체크 표시가 있는 습득 능력
  • 용도: 낚시 성장 속도를 높이는 패시브 효과

이 효과는 물고기 등장 확률 증가가 아니라 낚시 경험치 증가로 표시되어 있습니다.

📈 스킬 레벨 보상 예시

같은 스킬 화면에 표시된 레벨 7 보상:

  • +1% 행운
  • +0.4 체력

이 수치는 첨부 화면의 레벨 7 설명을 옮긴 것입니다. 모든 레벨에서 동일하게 증가한다는 뜻은 아닙니다.

실제 게임 화면: 낚시꾼 II, 레벨 7의 행운·체력 보상.

낚시 관련 상점·아이템

제공된 메뉴 화면에는 낚시 관련 아이템으로 보이는 아이콘 5개가 표시되어 있습니다. 아이콘별 이름과 가격은 툴팁이 없어 확정할 수 없으므로, 아래에는 실제 화면만 수록했습니다.

추가 제공된 인게임 메뉴 이미지. 아이템 이름·효과는 별도 툴팁 확인 전까지 기재하지 않았습니다.

추천 진행 순서　낚시 관련 메뉴 확인 → 낚시로 경험치 축적 → 낚시꾼 스킬 효과 확인 → 모은 재화로 필요한 물품 구매. 각 아이템의 정확한 용도는 서버 설정 자료 확보 후 도감에 추가할 수 있습니다.

안내 · PvP 아레나의 규칙과 보상은 실제 서버 내 안내에 따라 이용해 주세요.
10 / RANKS & PROGRESSION

안내 · 등급명·승급 조건·혜택은 서버 운영 설정을 확인한 뒤 상세 표로 업데이트됩니다.

설치 및 접속 순서

  1. 게임 버전 확인Minecraft Java Edition의 서버 접속 버전을 확인합니다. (팩 안내 기준 26.2)
  2. 접속기 설치전용 접속기가 공개되면 다운로드하여 설치합니다.
  3. 서버 입장안내된 서버 주소로 접속합니다.
QUESTIONS & ANSWERS

자주 묻는 질문

모드를 따로 설치해야 하나요?

추후 모드 설치가 필요한 서버로 준비 중이며, 전용 접속기와 설치 안내를 공개할 예정입니다.

리소스팩은 어떻게 적용하나요?

서버 설정에 따라 자동 적용될 수 있습니다. 문제 발생 시 운영자가 안내하는 리소스팩을 확인해 주세요.

명령어가 동작하지 않아요.

플러그인 설정과 권한에 따라 명령어가 다를 수 있습니다. 최종 안내가 업데이트되기 전에는 게임 내 도움말을 먼저 확인해 주세요.

서버 주소는 어디서 확인하나요?

서버 주소는 아직 공개되지 않았습니다. 추후 이곳에 안내할 예정입니다.
